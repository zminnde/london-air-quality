## Implementation

### 1. Subsampling

MDS is O(n²) memory and slow on 3,473 points. Use a random subsample of
800-1000 days (fixed seed for reproducibility, e.g. 42). State the sample
size in a markdown cell with brief justification — MDS sklearn becomes
impractical above ~1500 points and the visualisation does not benefit from
more anyway.

### 2. Sensitivity to initial solutions (the main task)

This is the critical part. Read the slides carefully — the lecturer's point
is that MDS has many local minima.

Run sklearn.manifold.MDS at least 6 times with DIFFERENT initial configurations:
- Use random_state values: 0, 1, 7, 42, 100, 2024
- IMPORTANT: set n_init=1 for each run. Do NOT use n_init=4 or higher,
  because sklearn would then run 4 inits internally per call and return
  the best — that would defeat the experiment by hiding the differences.
- Use max_iter=300 (sklearn default) or higher (500) to give each
  initialisation a fair chance to converge.

For each run record:
- Final stress value
- 2D embedding coordinates
- Number of iterations until convergence (mds.n_iter_)
- Time taken

### 3. Quantify how different the embeddings actually are

To confirm whether different stress values come from genuinely different
geometric solutions, OR from solutions that are equivalent up to
rotation/reflection, use Procrustes analysis from scipy.spatial.procrustes
between pairs of embeddings.

- Procrustes disparity ≈ 0 means the two embeddings are the same shape,
  just rotated/reflected/scaled. Same local minimum.
- Procrustes disparity substantially > 0 means genuinely different
  geometric solutions. Different local minima.

Build a small symmetric table or heatmap of Procrustes disparities between
all pairs of seeds. This directly addresses the lecturer's claim about
local minima — empirical evidence one way or the other.

### 4. Investigate embedding dimensionality m (bonus, mirrors lecture content)

- Plot final stress vs m
- This mirrors slide 4 (empirical f* vs m) and lets the report justify
  why m=2 is or is not a reasonable choice

This is a secondary analysis but ties the work directly to the lecture
